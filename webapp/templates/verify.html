Paste any untangle close certificate below. This page re-runs the same proof logic your browser can inspect: it recomputes the certificate's content hash and compares it to the claimed hash, checks the signature if one is present, and reports the proof-packet binding. A matching hash on a signed certificate confirms it came from untangle and is unaltered; on an unsigned certificate it confirms only that the file is internally consistent. The certificate is sent to /api/verify and verified in memory — it is not persisted, but treat it as a sensitive document.

Reproducible verdict The result is deterministic — re-run it anywhere and get the same answer.
